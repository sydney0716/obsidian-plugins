# Obsidian Plugins by sydney0716

This repository contains my personal collection of plugins for [Obsidian](https://obsidian.md).

## Plugins

### [Custom Folder Index](./custom-folder-index)
A plugin that automatically generates and maintains index notes for your folders.

- **Features:**
  - One-click recursive index generation.
  - Auto-updates when files are added/removed/renamed.
  - Blacklist system to exclude specific folders.
  - Customizable index templates.

---

## Installation

To install a plugin manually:
1. Download the latest release (or code) for the plugin you want.
2. Create a folder in your Obsidian vault: `.obsidian/plugins/<plugin-id>`.
   - For `Custom Folder Index`, use `custom-folder-index`.
3. Copy the plugin files (`main.js`, `manifest.json`, `styles.css`) into that folder.
4. Reload Obsidian and enable the plugin in **Settings > Community Plugins**.

# Obsidian 플러그인 모음 (by sydney0716)

이 저장소는 개인적으로 개발한 [Obsidian](https://obsidian.md) 플러그인들을 모아둔 곳입니다.

## 플러그인 목록

### [Custom Folder Index](./custom-folder-index)
폴더에 대한 인덱스 노트를 자동으로 생성하고 관리해주는 플러그인입니다.

- **주요 기능:**
  - 원클릭으로 하위 폴더까지 포함한 재귀적 인덱스 생성
  - 파일 추가/삭제/이름 변경 시 자동 업데이트
  - 특정 폴더 제외를 위한 블랙리스트 시스템
  - 커스터마이징 가능한 인덱스 템플릿

---

## 설치 방법

수동으로 설치하려면 다음 단계를 따르세요:
1. 원하는 플러그인의 최신 릴리즈(또는 전체 코드)를 다운로드합니다.
2. Obsidian 보관함(Vault) 내의 `.obsidian/plugins/<plugin-id>` 경로에 폴더를 생성합니다.
   - `Custom Folder Index`의 경우 폴더 이름으로 `custom-folder-index`를 사용하세요.
3. 플러그인 파일들 (`main.js`, `manifest.json`, `styles.css`)을 해당 폴더에 복사합니다.
4. Obsidian을 다시 로드한 후 **Settings > Community Plugins**에서 플러그인을 활성화합니다.
